## How to fill it in

The item text is shortened from Annex VII, and was checked against the official text on 2026-10-01. Annex VII asks for at least this information, as it applies to the product. Read Annex VII yourself before you fill in the index, and record in the source table when you did.

For each item, link the file or files in your Security evidence pack, from any tier, and write what is missing. An empty link is a finding, not a failure: write it down.
